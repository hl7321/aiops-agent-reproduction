# Spec Delta

## ADDED Requirements

### Requirement: 会话行内重命名与摘要卡片

左侧会话列表 SHALL 为每个会话提供行内重命名：点击编辑按钮进入输入，Enter 保存、Esc 取消；保存失败 MUST 保留服务端最后成功标题并显示可重试中文错误。右侧压缩摘要面板 SHALL 在选中的会话行下方就地展开摘要卡片，同一时间最多展开一张；点击同一行或卡片"收起" MUST 关闭卡片。摘要 MUST 按固定六段渲染，旧版摘要 MUST 按单一"摘要"段渲染，不得把摘要常驻在列表底部。

#### Scenario: 行内重命名

- **WHEN** 用户点击某个会话的编辑按钮并输入合法标题后按 Enter
- **THEN** 调用重命名 API，成功后左侧列表与右侧摘要面板同步显示新标题

#### Scenario: 重命名失败

- **WHEN** 重命名 API 返回 validation 或权限错误
- **THEN** 输入退出或保留可编辑，显示服务端最后成功标题与可重试错误，不乐观显示新标题

#### Scenario: 就地展开摘要

- **WHEN** 用户点击摘要面板中的某个会话
- **THEN** 该会话行下方展开摘要卡片，其他会话的卡片收起，列表底部不常驻摘要

#### Scenario: 六段摘要展示

- **WHEN** 展开的会话包含六段式摘要
- **THEN** 卡片按对话目标、关键事实与标识、已做决定、工具与证据、未解决事项、风险与注意事项顺序展示

#### Scenario: 旧摘要与收起

- **WHEN** 展开的会话说摘要没有固定标题，或用户点击"收起"
- **THEN** 旧摘要按单一"摘要"段展示；收起后卡片消失，原会话仍保持选中
