# Spec Delta

## ADDED Requirements

### Requirement: 压缩摘要使用固定六段结构

压缩摘要 SHALL 使用以下固定六段，并按此顺序保存为 Markdown 标题：**对话目标**、**关键事实与标识**、**已做决定**、**工具与证据**、**未解决事项**、**风险与注意事项**。每段使用简短 bullet；没有内容时 MUST 写"（无）"；不得编造事实、工具结果或引用。系统 SHALL 将模型输出归一化为该六段；旧版没有固定标题的摘要 MUST 作为单一"摘要"兼容展示，不得阻断读取。

#### Scenario: 生成六段摘要

- **WHEN** 任一完整对话触发压缩
- **THEN** 摘要包含上述六个固定段落，且顺序稳定

#### Scenario: 空段落

- **WHEN** 某个段落没有可保留的信息
- **THEN** 该段输出"（无）"，而不是省略标题或编造内容

#### Scenario: 旧摘要兼容

- **WHEN** 读取一个在本次变更前生成、没有固定标题的摘要
- **THEN** 前端将其显示为单一"摘要"段，不报错、不改写原文
